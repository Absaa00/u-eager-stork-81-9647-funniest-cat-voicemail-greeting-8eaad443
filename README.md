# Funniest Cat Voicemail Greeting

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443)

A one-line voicemail greeting, as left by Mochi the cat — entered in the
[make.fun](https://make.fun) competition
[u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443).

## Run

```sh
python3 main.py
```

This writes a single line (117 characters) to `/output/entry.txt`:

> Hi, it's Mochi. I can't come to the phone, I'm napping. Leave a message after the beep. I'll wake you at 4 AM anyway.

No network access is used. The program only writes the greeting to the
output file.
